# Veloop 0.3.1 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare, verify, push, tag, and publish Veloop 0.3.1 directly from `main` with the caret placement fix and no unrelated product changes.

**Architecture:** Tracked release metadata and tests define the public version contract. Local packaging scripts build and verify a universal ad-hoc signed DMG, while the tracked Homebrew cask records that exact DMG digest. Publication creates an immutable annotated tag and uploads the verified DMG plus bilingual update metadata.

**Tech Stack:** SwiftPM, XCTest, Objective-C/InputMethodKit, Bash, `hdiutil`, `codesign`, `lipo`, `plutil`, Git, and GitHub CLI.

## Installation notes

Veloop is ad-hoc signed and not notarized. Only remove quarantine from a copy downloaded from this repository:

```bash
xattr -dr com.apple.quarantine /Applications/Veloop.app
open /Applications/Veloop.app
```

Because the code hash changes between ad-hoc signed releases, macOS may require Accessibility to be enabled again after updating.
